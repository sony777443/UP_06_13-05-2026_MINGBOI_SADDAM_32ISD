# Telegram-бот расписания

Проект реализует Telegram-бота, который загружает файлы расписания с сайта колледжа и показывает расписание по курсам.

## Файлы

- `parser.py` — загрузка и кеширование расписаний, базовый парсер XLSX.
- `bot.py` — Telegram-бот с командами `/start` и `/courses`.
- `requirements.txt` — зависимости проекта.

## Установка

1. Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

2. Установите токен бота в переменную окружения:

```bash
set TELEGRAM_BOT_TOKEN=ваш_токен
```

3. Запустите бота:

```bash
python bot.py
```

## Использование

- `/start` — приветственное сообщение и кнопки быстрого доступа.
- `/courses` — список доступных курсов через inline-кнопки.
- `/refresh` — проверить обновления расписаний вручную.
- Кнопки Reply: `Показать курсы` и `Обновить расписание`.
- Выберите курс, и бот отправит текстовое расписание или файл.

## Автообновление

- Бот проверяет обновления расписаний автоматически.
- По умолчанию интервал составляет 5 минут для тестирования.
- Для продакшен-режима задайте `REFRESH_INTERVAL_SECONDS=86400`.

## Переменные окружения

- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота.
- `REFRESH_INTERVAL_SECONDS` — интервал автообновления в секундах.
