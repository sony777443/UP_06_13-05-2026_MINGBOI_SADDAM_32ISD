# Telegram-бот расписания

Проект реализует Telegram-бота, который загружает файлы расписания с сайта колледжа и показывает расписание по курсам.

## Файлы

- `parser.py` — загрузка и кеширование расписаний, базовый парсер XLSX.
- `bot.py` — Telegram-бот с командами `/start` и `/courses`.
- `requirements.txt` — зависимости проекта.

## Установка

1. Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

2. Установите токен бота в переменную окружения:

```bash
set TELEGRAM_BOT_TOKEN=ваш_токен
```

3. Запустите бота:

```bash
python bot.py
```
