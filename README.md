# Telegram‑бот расписания колледжа

**Автор:** [Имя Фамилия], группа [32ИСд]

## Краткое описание

🤖 Бот для удобного просмотра расписания занятий колледжа прямо в Telegram. Позволяет быстро найти расписание по курсам, автоматически обновляет данные и экономит время студентов.

## Что умеет бот
✅ Показывает расписание занятий на всю неделю по курсам  
✅ Использует inline‑кнопки для выбора курса и reply‑кнопки для быстрого доступа к основным функциям  
✅ Автоматически обновляет расписание раз в 5 минут  
✅ Парсит данные с сайта колледжа и кеширует их локально  
✅ Отправляет расписание текстом (если помещается в 3500 символов) или файлом (XLSX)  

## Стек технологий
- **Язык программирования:** Python
- **Библиотека для Telegram‑бота:** python-telegram-bot
- **HTTP‑запросы:** requests
- **Работа с Excel‑файлами:** openpyxl
